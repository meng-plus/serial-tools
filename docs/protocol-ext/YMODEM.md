# YMODEM 文件传输扩展包

通过 **YMODEM 协议** 双向传输文件（固件升级 / 备份）：

- **下发（PC → 设备）**：把本地升级文件分块发送到设备。
- **读取（设备 → PC）**：接收设备发出的文件并保存到 `serial-tools-data/exports/`。

本包**不内置**，需手动安装（与其它用户扩展包一致）。

## 安装

1. 打开「协议扩展」页 → 点「安装扩展包 (zip)」。
2. 选择 `public/protocols/demo/ymodem.zip`（或自行压缩 `public/protocols/demo/ymodem/` 目录内容：manifest.yaml + main.js）。
3. 安装完成后点「创建实例」，选择 YMODEM 协议、绑定串口 / TCP 通道。

## 使用步骤

### 下发（PC → 设备）

1. 在实例「参数配置」里选择**下发文件**（如 `upgrade.bin`）；其它参数按需调整。
2. 启动实例（点「启动」）。设备端进入 YMODEM 接收模式（通常设备会发 `C` 等待）。
3. 点「开始下发（发送文件）」→ 等待接收方 `C` → 自动逐块发送（CRC16-XMODEM 校验、超时重试）。
4. 进度经 `progress` 变量上监控；完成后日志显示共发送多少块。

### 读取（设备 → PC）

1. 启动实例后点「开始读取（接收文件）」，实例发出 `C` 请求。
2. 设备端启动 YMODEM 发送；实例逐块接收并校验，结束后自动保存。
3. 保存文件名取块0中的文件名，或「接收保存文件名」参数指定；文件落在 `serial-tools-data/exports/`。

### 取消

点「取消传输」：发送方向对端发 `CAN` 终止，双向回到待命状态。

## 参数说明

| 参数 | 说明 |
|------|------|
| `file` | 下发文件（`ctx.getFile('file')` 读取）；重启后需重新选择 |
| `block_size` | 数据块大小 1024(STX) / 128(SOH) |
| `timeout_ms` | 单块等待应答超时，超时重试 |
| `retries` | 单块最大重试次数 |
| `save_name` | 读取时保存文件名（空 = 用对端块0文件名） |

## 实现要点（供其它字节流协议参考）

- **字节流累积解析**：串口分帧按超时切帧，YMODEM 块可能在一次 `onRx` 中不完整。实现维护 `this.buf`，按帧头（SOH/STX/EOT/ACK/NAK/CAN/`C`）自行解析整块。
- **超时重试**：`onTick` 做看门狗，发送超时重发当前块 / 接收超时发 `NAK`。
- **CRC**：数据块用 `ctx.utils.crc16Xmodem`（poly 0x1021、初值 0）。
- **取消**：`CAN` 双向处理。
