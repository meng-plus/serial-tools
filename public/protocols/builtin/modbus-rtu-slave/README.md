# Modbus RTU 从站（内置示例协议）

随应用内置的示例参考实现：维护线圈表与保持寄存器表，应答 01/02/03/04/05/06/0F/10 功能码（CRC16-Modbus 校验）。用于本地主从闭环自测。

## 使用步骤

1. 打开「协议扩展」页 → 点「创建实例」，选择 Modbus RTU 从站、绑定**串口**通道。
2. 在「参数配置」中设置**从站地址**（addr），并配置**线圈表**与**保持寄存器表**。
3. 启动实例 → 从站开始应答该地址的 Modbus RTU 请求。

## 参数说明

| 参数 | 说明 |
|------|------|
| `addr` | 从站地址（1–247） |
| `coils` | 线圈表（01 读 / 05 写单线圈 / 0F 写多线圈）：地址 / 初始状态 / 名称 |
| `registers` | 保持寄存器表（03 读 / 06 写单 / 10 写多）：地址 / 数值 / 名称 / 单位 |
| `byte_order` | 数据字节序（大端 / 小端） |

## 动作

- `set_value`：修改寄存器值（kind = coil / reg）

## 自测

配合内置 `modbus-rtu-master` 主站（同通道上先启从站再启主站），即可本地主从闭环自测。
