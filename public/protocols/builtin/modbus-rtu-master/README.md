# Modbus RTU 主站（内置示例协议）

随应用内置的示例参考实现：周期轮询读取 RTU 从站寄存器（CRC16-Modbus 校验），支持多设备、超时重试与离线标记、参数变更即时生效。

## 使用步骤

1. 打开「协议扩展」页 → 点「创建实例」，选择 Modbus RTU 主站、绑定**串口**通道。
2. 在「参数配置」的**轮询表**中添加要读取的从站：名称 / 从站地址 / 功能码 / 起始寄存器 / 数量。
3. 调整轮询周期、响应超时与重试次数。
4. 启动实例 → 主站按周期逐条发送请求，响应寄存器值经变量推送，可在监控 / 图表 / 寄存器网格查看。

## 参数说明

| 参数 | 说明 |
|------|------|
| `poll` | 轮询表：设备名称 / 从站地址 / 功能码 / 起始寄存器 / 数量 |
| `cycle_ms` | 轮询周期（0 停止轮询） |
| `timeout_ms` | 响应超时 |
| `retry` | 超时重试次数 |
| `byte_order` | 寄存器字节序（大端 / 小端） |

## 动作

- `read_all`：立即读取一轮
- `clear_offline`：清除离线标记
- `write_reg`：写单寄存器（addr / reg / value）

## 自测

配合内置 `modbus-rtu-slave` 从站（同通道上先启从站再启主站），即可本地主从闭环自测。
