# Modbus TCP 主站扩展包

通过 **TCP 客户端通道** 周期轮询 Modbus TCP 从站（MBAP 封装，无 CRC），支持多设备、超时重试与离线标记。

本包**不内置**，需手动安装（与其它用户扩展包一致）。

## 安装

1. 打开「协议扩展」页 → 点「安装扩展包 (zip)」。
2. 选择 `public/protocols/demo/modbus-tcp-master.zip`（或自行压缩本目录内容：manifest.yaml + main.js）。
3. 安装完成后点「创建实例」，选择 Modbus TCP 主站、绑定 **TCP 客户端** 通道。

## 使用步骤

1. 在「参数配置」的**轮询表**中添加要读取的从站：名称 / 从站地址（unit）/ 功能码（03 读保持寄存器等）/ 起始寄存器 / 数量。
2. 调整轮询周期、响应超时与重试次数。
3. 启动实例 → 主站按周期逐条发送请求，响应寄存器值经变量推送，可在监控 / 图表 / 寄存器网格查看。

## 参数说明

| 参数 | 说明 |
|------|------|
| `poll` | 轮询表：设备名称 / 从站地址 / 功能码 / 起始寄存器 / 数量 |
| `cycle_ms` | 轮询周期 |
| `timeout_ms` | 响应超时 |
| `retry` | 超时重试次数 |
| `byte_order` | 寄存器字节序（大端 / 小端） |

## 动作

- `read_all`：立即读取一轮
- `clear_offline`：清除离线标记

## 自测

配合 `modbus-tcp-slave` 从站（同通道上先启从站再启主站），即可本地主从闭环自测。
