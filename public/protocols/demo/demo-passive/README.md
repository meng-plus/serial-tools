# 演示协议（被动解析）扩展包

按行分帧、按字段表解码并推送变量的**最小被动协议**，用于验证扩展包安装 / 卸载 / 参数导入导出全链路。

## 安装

1. 打开「协议扩展」页 → 点「安装扩展包 (zip)」。
2. 选择 `public/protocols/demo/demo-passive.zip`（或自行压缩本目录内容：manifest.yaml + main.js）。
3. 安装完成后点「创建实例」，绑定串口 / TCP 通道。

## 使用步骤

1. 在「参数配置」的**字段表**中定义解码规则：字段名 / 偏移 / 类型（u8 … f32be）/ 系数 / 偏移量 / 单位。
2. 选择行结束符（LF / CRLF）。
3. 启动实例 → 收到匹配的数据帧后按字段表解码，数值经变量推送，可在监控 / 图表 / 数据导出查看。

## 参数说明

| 参数 | 说明 |
|------|------|
| `fields` | 字段表：name / offset / type / scale / bias / unit |
| `eol` | 行结束符：LF / CRLF |

## 实现参考

本包由模板 `public/protocols/templates/custom-passive` 派生，是编写被动解析协议的最小示例。
