# Modbus TCP 从站扩展包

通过 **TCP 客户端通道** 模拟 Modbus TCP 从站（MBAP 封装）：维护保持寄存器表，应答 03 / 06 / 10 功能码。

本包**不内置**，需手动安装（与其它用户扩展包一致）。

## 安装

1. 打开「协议扩展」页 → 点「安装扩展包 (zip)」。
2. 选择 `public/protocols/demo/modbus-tcp-slave.zip`（或自行压缩本目录内容：manifest.yaml + main.js）。
3. 安装完成后点「创建实例」，选择 Modbus TCP 从站、绑定 **TCP 客户端** 通道。

## 使用步骤

1. 在「参数配置」中设置**从站地址**（unit），并在**保持寄存器表**中添加寄存器：地址 / 数值 / 名称 / 单位。
2. 启动实例 → 从站开始监听该通道上的 Modbus TCP 请求并应答。

## 参数说明

| 参数 | 说明 |
|------|------|
| `unit` | 从站地址（1–247） |
| `registers` | 保持寄存器表：地址 / 数值 / 名称 / 单位 |
| `byte_order` | 数据字节序（大端 / 小端） |

## 自测

配合 `modbus-tcp-master` 主站（同通道上先启从站再启主站），即可本地主从闭环自测。
